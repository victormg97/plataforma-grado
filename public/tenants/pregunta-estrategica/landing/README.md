# Assets del landing — pregunta-estrategica

Deja aquí las imágenes del landing page.

## Hero

- Archivo: `hero.jpg`, `hero.jpeg`, `hero.png` o `hero.webp`
- Ruta base: `/tenants/pregunta-estrategica/landing/hero.<ext>`
- El servidor detecta la extensión automáticamente en este orden: `.jpg → .jpeg → .png → .webp → .avif`
- Proporción recomendada: 4:3 (la imagen se recorta con `object-cover`)
- Tamaño sugerido: ~1200×900 px o mayor

Mientras no exista ninguna variante de `hero`, el recuadro muestra el logo
como fallback. Basta con dejar el archivo con cualquiera de las extensiones
aceptadas; no requiere cambios de código.
